知识卡片分区 · 四种做法

同一张卡的内容，四种排版。你要讲的不是"好看"，是"为什么这样排"——所以每一节下面都写了技术点和讲解口径。

01

严格竖排

最像西窗烛。也是唯一一个会把你的排版直觉整个掀翻的方案。

竖排 · 代码横置
  • 坐标系转了 90°。`writing-mode: vertical-rl` 之后，width 变成"能放几列"、height 变成"一列有多长"。所以竖排卡片的第一件事是先定高、不宽——定错了文字就断在奇怪的地方。
  • 最反直觉的一条：在竖排里 line-height 变成了列距，letter-spacing 变成了字距。（因为行内轴转了）这个点现场讲出来，评委立刻知道你真写过。
  • 中文字自动立正，但 for、100 会躺下转 90°。text-orientation: upright 能让它们站起来，可英文单词会散成一列单个字母——更难看。
  • 所以代码只能局部复位到 horizontal-tb。但内嵌横排块在竖排流里会被当成"一列"来排，块方向会错乱——所以这里我用绝对定位把它钉住。这是个真实的坑，不是偷懒。
  • 一句话总结：竖排是氛围，横排是信息。两者的边界就是这个分区的核心设计决定。

纸与印

横排 · 楷体 · 大留白
  • 去掉竖排、只留三样东西：纸的色（#FDFBF3 带一点黄）、软阴影 + 1px 的内描边、一个 mix-blend-mode:multiply 的红印。
  • 留白不是"没东西"，是排版动作。这里靠 justify-content:space-between 把内容顶到上下两端，中间自动空出来——比自己算 margin 稳得多。
  • 字距是灵魂。letter-spacing:.3em + line-height:2.56，同样的字立刻从"网页"变"书页"。
  • 代价：不再"古"，只剩"雅"。但代码是横排的自然状态，可读性最高。
  • 技术点（讲这个）：纸纹是 feTurbulence 噪点滤镜 + mix-blend-mode:multiply 叠上去的，零图片请求。这一句很值钱。

点一下翻面 ↻
  • 翻面是把"竖排 vs 代码"这个矛盾变成两个界面，而不是硬塞在一个界面里。正面可以做满分的氛围，背面可以做满分的可读性。
  • 三行 CSS：transform-style:preserve-3d 让子元素保留三维、backface-visibility:hidden 藏住背面、背面自己 rotateY(180deg) 站好位。
  • 交互上白赚一次动作。现场演示时"翻牌"这个动作本身就抓人，比你多讲三句话有用。
  • 代价：多一次点击才能看见代码。所以一定要有个暗示（下面那行"点一下翻面"），否则评委不知道能翻。
  • 教学上的真正价值：先给一句能记住的话，再给代码。卡片不是装饰，它是记忆钩子。这句话直接就是你的答辩理由。

1 / 4
  • scroll-snap-type: x mandatory 让手指一滑就必然停在卡片的对齐线上，不会停在两张卡中间。
  • 子元素 scroll-snap-align: center 决定"停在哪"。
  • 隐藏原生滚动条的 scrollbar-width:none + ::-webkit-scrollbar{display:none} ——两行都要写，因为 Firefox 只认前者、Chrome/Safari 只认后者。这是个很好的细节题。
  • 箭头那一步怎么算？别写 cardWidth + gap——gap 一改就错。用 cards[1].offsetLeft - cards[0].offsetLeft，差值天然包含间距，改 CSS 也不用改 JS。这是个很讨巧的写法。
  • scrollTo({behavior:"smooth"}) 自带动画，不需要任何缓动库；直接给 scrollLeft 赋值反而会被 mandatory 的吸附立刻弹回去（我踩过，实测赋值后读回来还是 0）。
  • 宽度是被故意压窄的。1200px 的页面上如果让它铺满，一次能看见三张——那就不叫"翻"，叫"列表"。压到 340px（一张 312 卡 + 一点邻居），"翻"的感觉才出来。这是设计决定，不是顺手。
  • 这个方案的真正好处是"数量感"。你把 30 张卡装进一个可以左右滑的册子里，比在页面上铺 30 个方块有说服力得多。

我的建议：03 装进 04

用「卡册」做容器，里面每一张都是「翻面」卡。横滑负责"我有多少"（数量感、演示节奏），翻面负责"这张讲什么"（氛围 + 代码）。

01 竖排别当主方案，但当"彩蛋"。放进某一张卡的正面，或者做一个"书卷模式"开关——它好看，但它和代码抢同一块版面，全面竖排会把你的可读性拖死。

02 是你万一没时间的退路。它很好实现，而且不丢人：纸、字距、留白、红印四样齐了，就已经比九成学生作品干净。

06

答辩时可以直接念的四段

/* ① 竖排只改一个属性，但坐标系整个转了 */
.vtext {
  writing-mode: vertical-rl;      /* 从右往左排，行从上往下 */
  text-orientation: upright;     /* 中文立正，英文不再躺倒 */
}

/* ② 纸纹：零图片请求 */
.paper::before {
  background-image: url("data:image/svg+xml,<feTurbulence/>");
  mix-blend-mode: multiply;        /* 叠上去像油墨，不像贴纸 */
}

/* ③ 翻面：三行 */
.inner { transform-style: preserve-3d; }
.face  { backface-visibility: hidden; }
.back  { transform: rotateY(180deg); }

/* ④ 卡册：四行，零 JS */
.deck   { scroll-snap-type: x mandatory; }
.card   { scroll-snap-align: center; }

这四段就是你这个分区的全部代码量。加起来不到 20 行，但每一行都能讲出"为什么"。
