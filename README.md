# 小柚 · 陪伴式编程入门

> 给一个人写代码的大一新生的陪伴式编程入门 —— 报错有人问，卡住有人陪，答对有人高兴。

一个纯前端的对话式教学 H5。没有框架，没有构建，没有后端，双击 `index.html` 就能跑。

---

## 它不一样在哪

一般的学习产品，聊得多就涨好感。这里的「默契度」**只因为答对而涨**。

教学的目标函数是「少说、多做、做对」，陪伴的目标函数是「多聊」。这两个是对立的。把它们拧到一起的唯一办法，就是让好感度绑在掌握度上——这是这个项目唯一能立住的设计判断。

## 技术上最关键的一个决定

**判题不放给模型。**

选择题的答案写在本地题库里，模型只负责「讲为什么」。

这样最坏的情况是讲解不够精彩，而不是判错。对一个教学产品来说，判错是致命的，讲解平庸不是。

## 怎么跑

```bash
# 直接双击 index.html 也可以
py -m http.server 8767 --directory . --bind 127.0.0.1
```

> Windows 上注意：如果 `python` 指向 Python 2.7，请用 `py`。
